# Reports Directory

This folder contains the exported artifacts used by the Streamlit dashboard and the project report.

## Main Report

- `portfolio_credit_risk_report.md` - concise project report covering model performance, risk segmentation, scorecard benchmarking, calibration, and business decision implications.
- `scorecard_benchmark_report.md` - supporting note for the WOE logistic scorecard benchmark.

## Dashboard Data

These CSV files are intentionally committed because `app.py` reads them directly when the Streamlit dashboard runs online:

- `model_metrics.csv`
- `decile_lift_gains.csv`
- `threshold_business_decisions.csv`
- `test_scores.csv`
- `scorecard_vs_ml_comparison.csv`
- `scorecard_points.csv`
- `scorecard_scaling_params.csv`
- `scorecard_test_scores.csv`
- `shap_importance.csv`
- `iv_summary.csv`
- `calibration_table.csv`

## Supporting Modeling Artifacts

Additional CSV files document intermediate modeling outputs such as feature importance, WOE bins, scorecard coefficients, and risk segments. They are kept for reproducibility and auditability, but the main reader-facing entry points are the repository README, the Streamlit dashboard, and `portfolio_credit_risk_report.md`.

## Figures

The `figures/` subfolder contains EDA, model diagnostic, lift/gains, IV, calibration, SHAP, and scorecard plots generated by the modeling pipeline.
